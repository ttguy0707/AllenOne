# 运动记录简化：训记参考与 AllenOne 方案

更新：2026-10-03。状态：已实现并通过录入、数据兼容与交互回归；发布状态见 PROJECT.md。下面的具体布局为代理实施选择，不冒充训记实测。

## 用户确认的方向

- 当前添加运动记录过于复杂，特别不接受需要处理“草稿”的流程；要求参考训记。
- 保留力量、跑步、骑行和篮球，以及训练中记录和结束后补记。
- 用户要求逐步完成，先从训记参考开始。后续精灵需求见 PROJECT.md 与 D027。

## 实际参考与证据边界

参考 [训记 App Store 官方页面](https://apps.apple.com/cn/app/id1464915553) 的开发者说明及三个公开截图（训练计划、训练记录、动作精读），并查阅 [官方网站](https://trains.xunjiapp.cn/)。这是公开资料分析，未安装登录训记，也未验证其全部交互或内部数据行为。商店截图可能早于当前版本。

截图可直接观察到：

1. 训练页围绕动作卡片与逐组的重量、次数、完成勾选展开，顶部显示计时和完成入口。
2. 增加一组放在动作卡片内，添加动作位于训练页底部；说明和历史等信息在动作详情展开。
3. 计划页提供个人模板入口，训练记录可以围绕已有安排组织。

不据此断言训记是否存在草稿、怎样自动保存、精确点击次数或如何处理训练中断。下面的简化策略是 AllenOne 的设计选择，不冒充训记实测行为。

## 改动前的具体问题

代码依据：app/app.js 中 workoutForm、workout / workout-edit / use-template 操作分支和 saveDraft。

| 改动前行为 | 用户负担 | 当前实现 |
| --- | --- | --- |
| 新训练先展示日期、必填时长和独立计时按钮 | 训练还没结束就要求填总时长 | 现场训练进入即计时，完成时计算；补记才手填时长 |
| 下拉选择动作后，还要单独点击添加 | 每个动作重复两个步骤，难浏览 | 搜索动作名或部位，一次勾选多个动作 |
| 组数据默认重新填，虽然已有上次记录提示 | 相同训练反复输入 | 提供沿用上次完成组的重量／次数，当前完成状态重新确认 |
| 日期、感受、模板、动作说明、休息设置同时展开 | 主任务被次要选项打断 | 首屏聚焦动作和组；其他内容按需展开 |
| 未完成草稿阻止新建、使用模板和编辑历史 | 用户必须先理解并清理草稿 | 去掉草稿管理入口和阻塞弹窗；进行中的训练在后台保留 |

## 已实施流程

### 力量：现场训练

首页点“力量训练” → 选择动作或已有模板 → 填重量／次数，做完一组点勾 → “完成训练”。

- 当天日期默认带入，计时自动开始；模板是可选快捷入口，不强制建立计划。
- 一页完成记录，采用每动作一张卡片和紧凑组表；添加一组沿用前一组数值，但不自动标记已完成。
- 有上次记录时显示参考，支持直接沿用数值；无历史时不虚构训练重量或实际完成组。
- 主操作固定为“完成训练”；时长随训练计算，不再另点结束计时再保存。
- 组间休息继续手动启动，不擅自改成自动开始；时长设置折叠。
- 备注、动作说明、保存为模板置于次级入口。

### 力量：补记

力量页提供次级“补记”入口 → 默认今天，可改日期和总时长 → 选择动作，填写实际完成组 → 保存。

- 补记不启动现场计时。
- 现场／补记都需要明确完成至少一组；未填的空白组不保存为实际训练，沿用历史值不自动勾选完成。

### 跑步／骑行

首页点运动类型 → 填距离和用时 → 保存。

- 今天为默认日期；修改日期和感受为次级选项。
- 配速／均速自动计算；无标题、计划或草稿管理前置步骤。

### 篮球

首页点篮球 → 填开始和结束时间 → 保存。

- 保留跨午夜的实际日期，不添加比分、距离或感受等非必要输入。

## 中断保护与数据边界

- “去掉草稿”指去掉用户需要管理草稿的流程，不代表清除现有未完成内容或取消防丢保护。
- 训练意外退出后提供“继续训练”；同类型入口直接继续已有训练，不再要求先处理草稿。
- 进行中的力量训练不能阻止记跑步／骑行／篮球，也不能阻止编辑历史记录。
- 保存其他运动不能顺带覆盖或删除进行中的力量训练；明确取消已有训练才允许丢弃它。
- 新 recording_sessions 按运动类型／历史记录 ID 独立保存，兼容旧 state.draft；同标签页的同步恢复日志保护最后一次输入，并用 revision 防止覆盖另一页面新数据。完整说明见 DATA_FORMAT.md。
- 不改变已保存记录、数据库名、精灵分和周结算。

## 验收结果

1. 从首页记录跑步／骑行只需进入、填写两项、保存；篮球只有起止时间。
2. 力量训练无需先填总时长，能批量加动作、逐组勾选、一次结束保存。
3. 前后台切换／刷新可继续训练；已有训练不阻塞其他记录，成功保存后不会被延迟自动保存恢复成旧内容。
4. 使用历史值不等于自动完成新训练；补记和现场计时各自准确。
5. 浅／深主题、390×420 短视口（真机键盘待验收）、历史编辑、导出／恢复和离线仍可用。

补充：新增组与从动作选择页返回时保留训练滚动位置；新增组保留键盘焦点。模板与手动补记、历史计时改为手填、Escape 返回层级、快速刷新和保存失败恢复均有回归。
