# 精灵系列与动态 3D 原型

日期：2026-10-02

**当前入口**：主应用位于 `../app/`，本机 http://127.0.0.1:4180；已设计并接入 24 种动态角色（生肖12＋鸟类6＋海洋6），逐只姿态见 [PET_ROSTER.md](PET_ROSTER.md)。本文下方四角色内容保留为探索原型历史，不能据此认为主应用仍只有4只。

最新：用户选择预渲染立体动画，实时模型／旋转交互已被替代，见 `ANIMATED_COMPANIONS.md`；下文模型内容保留为历史。

## 已确认方向

- 精灵需要动态 3D，不能只交付静态风格图。
- 角色库包含十二生肖、常见海洋生物、鸟类及鹰类，不局限于龙。
- 首版过于简化，用户要求更精致；第二版正在接受美术评审，不能把技术检查通过视作用户接受造型。
- 用户要求姿势各异、20 多种精灵；已授权设计完成后开发 App。当前具体名单与程序模型为代理设计，最终美术尚未逐只验收。
- 动态与系列要求不改变现有计分、独立培养、永久解锁规则；解锁顺序不由本表确定。

## 当前可运行原型

入口：[prototypes/pet3d/index.html](../prototypes/pet3d/index.html)，运行说明见 [README](../prototypes/pet3d/README.md)。

| 角色 | 原型动作 |
| --- | --- |
| 月芽兔 | 呼吸、眨眼、摆耳、打招呼时轻跳 |
| 青芽龙 | 呼吸、眨眼、连续曲面摆尾、扇翼、轻跳 |
| 浪花豚 | 悬浮游动、上下摆尾、胸鳍摆动、打招呼回应 |
| 逐风鹰 | 振翅悬停、眨眼、打招呼时加快振翅 |

- 四种角色可切换，支持拖动环绕、缩放、自动环绕、暂停、键盘操作与成长预览。
- 使用原创程序几何模型与本地 Three.js 依赖；不需要付费 3D 服务。
- 当前为第二版造型和技术探索，不代表完整图鉴已实现或最终美术已确认。
- 五档成长仅为交互演示；角色选择、形态变化均不修改正式分数，且未实现任何饮食或训练存储。
- 原型选择软质玩具外观方便比较体型，不视为用户已确认该风格。

### 第二版细化内容

- 兔：平滑衔接的身体与脸颊、贴合耳廓的内耳、胡须、趾线及玉色挂饰。
- 龙：连续身体与尾部、弯曲角、分层腹甲、带翼骨的翼膜和爪部细节。
- 海豚：吻部到尾柄的一体曲面、腹部渐变、背鳍／胸鳍／尾鳍、嘴线与呼吸孔。
- 鹰：分层飞羽与羽轴、胸部覆羽、颈羽、弯喙和脚趾爪部。
- 公共：程序表面纹理、分材质、环境反射、柔和光照；不同物种保持不同动作节奏。
- 新截图：`assets/pet3d-v2-{rabbit,dragon,dolphin,eagle}-{desktop,mobile}.png`；保留首版截图用于比较。

## 验证与限制

- Windows Edge 已通过实际浏览器测试：四角色第 1／3／5 档形态、渲染、动作暂停、打招呼、自动环绕、方向键旋转、390px 页面无横向溢出及减少动态效果偏好；重复切换后几何体／纹理计数稳定，无 JS、着色器或资源请求错误。
- 已目视检查桌面角色与手机布局；手机宽度使用更宽视场以容纳展翼角色。
- 仅本机预览，未部署到公网，未进行真机 iPhone Safari 性能和触控验证。
- 原型尚未产出可复用 GLB 模型、骨骼动画或正式精灵资源包。完整图鉴按后续选择的风格分批制作。
