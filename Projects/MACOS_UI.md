# AllenOne：macOS 风格与交互质量

更新：2026-10-03。用户明确要求更高级、美观、macOS 风，并要求多个子 agent 交叉评审；替代此前 Google Material 主视觉方向。保留 AllenOne 品牌 PNG、单色图标与浅／深／跟随系统。

## 当前实现

- `app/macos.css` 是最后加载的视觉覆盖层，沿用已有结构与主题键；旧 Material 样式作为基础与历史保留。
- 系统字体、清楚的字号层级、中性背景、细分隔线、轻阴影；按钮圆角约 9px，卡片约 14～18px。蓝色用于主要操作与选中状态。
- 桌面侧栏有轻微半透明材质；手机底栏保持单层选中态、安全区和完整五页入口。
- 表单数字优先，次要信息折叠；训练页页头／页脚固定在布局内，正文独立滚动，给键盘与短可视区域留空间。
- 控件反馈限制在短暂颜色、阴影、位移变化；弹窗约 180ms 出场，不引入大范围炫光或循环装饰动画。减少动态效果设置关闭入场动画。
- 精灵仍为预渲染角色动画，不恢复实时模型或拖动旋转。

## 交叉评审与验收

- visual_review：390／1440、浅深主题、首页密度、精灵区域高度、训练控件、短视口与焦点。
- interaction_review：录入、模板、中断／刷新、Escape、历史编辑、焦点恢复；修复可复现问题后回归。
- data_review：旧 draft 与新 recording_sessions、备份、并发 revision、输入恢复日志不能复活已完成记录。
- 已修复主按钮对比度、双层选中背景、首页舞台高度、弹窗焦点恢复、添加组滚动／焦点保持；浅深主题、390／1440 五页、44px 组控件、短视口与减少动态效果检查通过。
- 390×420 视口是键盘空间代理检查，不宣称替代 iPhone 真机键盘、Safari 后台或触控验收。

## 持续约束

- 不改变数据库名、既有完成记录、分数或成长门槛。未完成记录兼容说明见 DATA_FORMAT.md。
- 精灵只显示其自身当前分数对应形态，无手动外观／阶段预览。未解锁图鉴呈灰色。
- 发布使用原生产网址，先核对 Cloudflare 实际仓库来源；避免把推送成功误报成线上更新成功。
