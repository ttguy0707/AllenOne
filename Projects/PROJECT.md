# 项目概况

最后更新：2026-10-03

## 目标与约束（已确认）

- 应用名 **AllenOne**；界面采用 Google 系风格，替代此前用户不接受的装饰性风格。具体组件与色值为代理实现选择。

- 开发供用户自己使用的健身、运动记录工具，主要在 iPhone 上使用。
- 产品形式选择 PWA，可通过浏览器访问并添加到 iPhone 主屏幕。
- 开发环境为 Windows。
- 成本目标为不花钱或低价；尚未确定具体预算上限。
- 运动范围包含力量训练、跑步、骑行和篮球，基本记录粒度见 `DESIGN.md`。
- 记录目的包括坚持运动与周汇总、观察进步、按计划训练、记录运动感受；四项均需要，暂未排序。
- 采用手动输入，可提供选项辅助录入；同时支持运动过程中记录和结束后补记。
- 力量记录每组重量与次数并可查看上次记录；跑步与骑行记录距离和用时，分别计算配速与均速；篮球只输入起止时间。
- 训练计划采用可复用模板，包含动作、目标组数和次数，训练时直接选择。
- 内置常见动作并支持自定义动作；按动作素材情况选择简单动画或图片。
- 力量训练以器械较齐全的健身房场景为主，内置动作库围绕该场景组织。
- 支持完成一组后手动启动休息倒计时，休息时间可调整。
- 第一版休息倒计时只需 App 前台提醒。
- 力量训练点击开始／结束自动计算总时长；补记时可以手填时长。
- 第一版数据仅保存在 iPhone 本机，无需登录，提供导出与导入备份。
- 用户计划使用约一年，之后可能迁移到其他 App；必须定义并说明数据格式，使历史记录可导出、理解和转换。
- 当前无需将苹果健康或 Apple Watch 自动同步列为必需能力。
- 回看范围：运动日历与详情、周／月运动天数和总时长及分类次数、同一力量动作的历史重量与次数、跑步／骑行累计距离与单次数据、篮球次数与累计时长。
- 新增放纵餐统计：每周不超过 1 次达标（含 0 次），超过 1 次超标；连续达标加分按 1、2、4……翻倍，连续超标扣分按 2、4、8……翻倍；达标与超标切换时倍数重置。
- 总分初始 60，首只精灵初始 60，后续新精灵初始 0；总分与精灵分独立维护，均无上限、最低为 0。总分用于历史统计，精灵自身分数驱动等级、大小与外观，满级后可解锁其他精灵。
- 每周同一规则变化值分别计入总分与结算时当前装配精灵，分别以 0 为下限；其他精灵不受影响，可随时切换装配。总分不等于各精灵分之和，不随切换重置。
- 精灵随自身分数降低而降级、变小，已解锁精灵永久保留。
- 周计分按北京时间周一至周日；下周首次打开时确认上周次数后结算，无记录周待确认；首次使用从下一个完整周计分。
- 允许补记、编辑和删除；修改历史餐记录后重算受影响周及后续分数，保留原周精灵归属与已解锁精灵。
- 后续精灵满级门槛逐步提高；先制作多种视觉风格供选择，具体门槛与最终风格待定。
- 精灵需动态 3D，角色库覆盖十二生肖、常见海洋生物和鸟类（含鹰类），不局限于龙。
- 用户认为首版造型过于简化，要求更精致；可运行与有动画不足以代表美术质量达标。
- 用户进一步要求姿势各异，十二生肖＋鸟类＋海洋共 20 多种；已授权由代理完成设计后开始开发 App。
- 用户再次要求精修粗糙模型，提升整个 UI 的精致度，并提供浅色、深色主题。

- 最新视觉决策：放弃现有实体 3D 模型，改用预渲染立体角色动画，包含待机、互动与成长表现；取消实时模型和拖动旋转。具体素材质量待评审，详见 `ANIMATED_COMPANIONS.md`。
