# 预渲染立体角色动画

更新：2026-10-03。当前 UI 见 MACOS_UI.md，本文替代旧实时模型及两套外观加缩放的实现。

## 已实现

- 24 种角色：十二生肖 12、鸟类 6、海洋 6；马与鳐已补齐。各角色保留既有 ID 和分数。
- 每种 5 个成长形态，每阶段 4 帧，共 120 个形态、480 帧。初生／幼年／成长／成年／盛年通过头身比、肢体、口鼻、毛羽或鳍形变化体现年龄，另有小幅显示尺寸增长。
- 主舞台只展示精灵自身当前分数对应阶段。取消阶段选择与外观预览；未解锁图鉴为灰色缩略图，点选只显示解锁说明。
- 运行图集为本地 WebP（24 套约 13.37 MiB，另有小缩略图），原始 PNG 不进入发布目录。旧 v1 运行图集已替换。
- Canvas 2D 播放预制帧；无 Three.js、WebGL、拖动旋转。每阶段使用自身帧互动，不会退回幼体。
- 可暂停；减少动态效果默认暂停；页面隐藏时停止推进，返回后恢复；主题切换保留 Canvas。
- 动画是轻量逐帧表现，并非视频或连续骨骼动画。120 个形态是独立绘制画面，不能称为 120 套可编辑 3D 模型。

## 生成与资源

全部由内置 imagegen 生成，没有新增付费 API 或密钥接入。原始图与实际提示词保留：

- assets/animation-source/*-growth-v2.png：24 张透明原图。
- assets/growth-prompts-v2.json：22 种最终提示词与项目相对路径。
- assets/growth-prompts-horse-ray.json：马与鳐的最终提示词。
- app/assets/companions/*-growth-v2.webp：4 列 × 5 行运行图集；*-poster-v2.webp 为图鉴缩略图。
- app/pet-animation.js：资源、行列与节奏；app/pet-view.js：播放与生命周期。
- scripts/prepare-growth.mjs：按透明轮廓提取 20 个完整主体，保留原 alpha 与抗锯齿边缘，分离相邻翅尖，再归一到每阶段统一尺寸与基线。仅作切帧／格式转换，不重画角色。
- scripts/prepare-companions.mjs：兼容入口，调用新打包器。

原图的行高并不总是等分，不能直接按固定格裁切。最终 24 张原图哈希唯一；480 个主体非空且没有触碰原图边界。已查看五阶段联系图，确认整体年龄差异及裁切完整性。测试输出在忽略目录 test-results/growth/。

## 验收

tests/animation-browser.mjs 检查全部 24 种 × 5 阶段离线加载、实际阶段取帧、锁定项灰度／无外观预览、暂停／互动／减少动态效果、系统主题与不写业务分数。最终发布结果见 PROJECT.md。

多 agent 交叉评审覆盖素材、交互、视觉与数据；美术是否符合用户审美仍由用户判断。iPhone Safari 真机触控、后台恢复、性能与耗电待真机验收。
