# 第一版需求清单

更新日期：2026-10-02

状态：已获用户授权开始开发。本文保留确认的需求；当前实现与验证见 `IMPLEMENTATION.md`。具体成长参数等代理默认值不自动转为用户已确认要求。

## 使用目标

在 Windows 上开发供个人在 iPhone 使用的 PWA，免费或低成本。满足坚持运动、观察进步、按计划训练和记录感受四项目的。计划使用约一年，之后能够取出完整数据以迁移至其他 App。

## 已确认功能

| 模块 | 第一版需求 |
| --- | --- |
| 录入方式 | 同时支持运动中记录与结束后补记；日期默认当天，可补记其他日期 |
| 力量训练 | 选择动作，按组记录重量与次数；能查看同一动作上次记录 |
| 力量总时长 | 开始／结束自动计算；补记可手填总时长 |
| 训练模板 | 保存动作、目标组数和次数，训练时直接选择模板 |
| 动作库 | 面向器械齐全的健身房，内置常见动作并支持自定义动作 |
| 动作示意 | 按素材情况使用简单动画或图片；具体动作和素材待选 |
| 组间休息 | 完成一组后手动启动倒计时，可调整休息时间；第一版只需 App 前台提醒 |
| 跑步 | 手填距离与用时，自动计算配速 |
| 骑行 | 手填距离与用时，自动计算均速 |
| 篮球 | 仅输入起止时间，计算时长 |
| 运动日记 | 力量、跑步、骑行可填写备注与感受；篮球保持简化输入 |
| 历史回看 | 运动日历及单次运动详情 |
| 周／月汇总 | 运动天数、总时长、各类运动次数 |
| 力量进步 | 同一动作的历史重量与次数 |
| 跑步／骑行统计 | 累计距离及每次距离、用时、配速或均速 |
| 篮球统计 | 次数、累计时长 |
| 放纵餐统计 | 记录并统计每周次数；不超过 1 次（含零次）达标，超过 1 次超标；输入字段待设计 |
| 周计分 | 连续达标 +1、+2、+4……，连续超标 -2、-4、-8……；达标／超标切换时倍数重置；同一规则变化值分别计入总分和结算时装配精灵，各自最低 0、无上限，其他精灵不变；周结算流程待设计 |
| 总分统计 | 初始 60，独立维护，用于历史统计，不参与精灵成长，不以各精灵分之和替代 |
| 周结算 | 北京时间周一至周日，下周首次打开确认次数后结算；无记录周待确认；首次使用从下一个完整周计分 |
| 历史修正 | 允许补记、编辑、删除；历史餐记录变更重算受影响周及后续分数，保留原周精灵归属，已解锁精灵保留 |
| 精灵养成 | 首只 60 分、新精灵 0 分，每只独立培养，可随时切换装配；自身分数越高越高级、越大、越好看，扣分会降级变小；满级后可解锁其他精灵，已解锁永久保留；成长阈值待定 |
| 精灵表现与图鉴 | 动态 3D，造型精致、姿势各异；覆盖十二生肖、常见海洋生物、鸟类及鹰类，20 多种。当前设计选择为 24 种，见 `PET_ROSTER.md` |
| 数据保存 | 第一版只在本机保存，无需登录 |
| 备份与迁移 | 导出／导入备份，附明确的数据格式和说明，保留可供后续转换的原始记录 |

## 典型流程与后续验收场景

这些场景描述产品预期，已实现与已验证部分以 `IMPLEMENTATION.md` 的测试记录为准，不能据此宣称真机已验收。

1. **现场力量训练**：选择已保存模板，开始训练，查看动作示意及上次记录，逐组录入实际重量和次数，按需手动启动休息倒计时，结束后保存总时长。
2. **力量补记**：选择实际训练日期，录入动作与逐组数据，手填总时长，保存后可从日历查看。
3. **跑步／骑行补记**：填写日期、距离与用时，得到对应配速／均速；记录进入单次详情与累计统计。
4. **篮球记录**：输入起止时间即可保存，并进入次数与累计时长统计。
5. **回看进步**：在日历查看一次训练的完整记录；按周／月查看运动汇总；按动作比较重量与次数历史。
6. **一年后迁移**：导出原始记录与格式说明，能理解每条运动及逐组数据的日期、单位和含义；在本 App 的空白环境恢复备份后，记录和关联保持一致。第三方导入需按目标 App 的实际格式另行适配。

- 技术栈、托管方案与具体费用。
