## 代码与验证

- app/app.js 为页面与提交协调，workout-ui.js 为记录界面，core.js 为业务／校验，store.js 为事务与 revision。
- macos.css 最后覆盖视觉；material.css 保留基础结构；品牌 A 生图与单色 Material Symbols 本地素材继续使用。
- pet-animation.js / pet-view.js / assets/companions/ 为当前 24 套五阶段图集。
- scripts/build.mjs 发布 dist/，排除旧实时模型与旧图集。原图、设计记忆、测试不发布。
- npm test：15 项核心与未完成记录兼容测试，包含一年虚构记录往返、精确大整数与异常备份拒绝。
- npm run check：串行执行餐／备份、四运动、输入恢复与并发、计时、自定义动作、周结算、精灵、macOS 主题与交互专项。
- 浏览器检查使用独立 Edge 上下文和虚构数据，不操作用户真实运动记录；截图／输出位于忽略目录 test-results/。
- 图集完成 24 张唯一源图、480 主体非空及边界检查，并目视检查五阶段联系图。

## 默认值与边界

成长阈值仍为 120×2^解锁序号，首次满级给一次解锁资格；这些是既有设计默认值，不能默认为用户逐项确认。运动以开始日期统计，力量总用时含休息。备份 schema_version 仍为 1.0.0，recording_sessions 是可选兼容扩展；旧版本不提供多项恢复界面，迁移说明见 DATA_FORMAT.md。

没有后端、账号、跨设备同步或新增付费服务。iPhone Safari 安装、真机键盘／触控、后台和长期本地存储、耗电仍待验证。角色和界面最终审美由用户确认。

历史实时模型、Atelier／Material 方向与旧 22 套动画方案保留在 Git 历史和专题历史说明；不作为当前交付能力。
