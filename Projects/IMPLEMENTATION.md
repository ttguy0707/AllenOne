## 入口与架构

- 根目录 `README.md`：启动、构建、验证。
- `app/app.js` / `style.css`：今日、记录、伙伴、放纵餐、我的；手机底部导航、桌面侧栏。
- `app/core.js`：日期、完整周、精确整数周计分、独立余额、历史重算、领养、备份校验和 CSV。
- `app/store.js`：IndexedDB 原子写入，提交完成后才提示成功；revision 防止多页面旧状态覆盖。
- `app/catalog.js` / `pet-animation.js` / `pet-view.js`：24 角色目录，22 套预渲染图集；Canvas 2D 播放当前角色，静态小预览用于图鉴。旧模型仅保留为源码历史。
- `app/exercises.js`：12 个内置动作定义和代码生成的姿态辨识 SVG；支持自定义动作与口径。
- `app/manifest.webmanifest` / `sw.js`：主屏幕入口、PNG 图标、完整静态资源缓存。构建按内容更新缓存版本，无远端 CDN。
- `scripts/build.mjs` 将主应用与本地动画资源输出到 `dist/`，排除旧模型与 Three.js 资源，`scripts/server.mjs` 只监听 127.0.0.1:4180。

没有后端、登录、云同步或新增部署费用。角色素材使用会话内置 imagegen，无额外 API 密钥或付费服务接入。没有向用户数据库注入模拟健康记录。

## 设计默认值

- 24 种名单见 PET_ROSTER.md；具体物种和造型属于当前设计，未逐只获美术验收。
- 五阶段和递增门槛 120×2^解锁序号，首次满级免费一次领养资格，标记 growth-draft-v1；后续改参数需要迁移，不能静默重写已有培养规则。
- 运动统计按开始日期；力量时长含组间休息，不提供暂停扣除。公斤、米、秒为存储单位。
- 训练模板一个动作共用目标次数；CSV 为运动逐组扁平视图，不包含全部模块，完整归档须保留 JSON。
- 导入完整替换，不合并；先预览、勾选确认，可先导出当前数据；重复恢复不重复累加。

## 验证

- `npm.cmd test`：8 项核心测试通过，覆盖周界限、计分切换、独立截断、原归属重算、永久解锁、90周大整数和一年四类运动备份往返，以及异常备份拒绝。
- `npm.cmd run check`：实际 Edge 浏览器通过四运动、力量逐组、模板、餐录入、刷新恢复、JSON 恢复、24伙伴状态（22动画＋2待补充）、5个390px页面、草稿恢复、离线界面与动画；无 JS／资源错误。
- `node tests/settlement-browser.mjs`：通过空周不自动计分、6周达标精确奖励、领养装配、独立最低0、历史修正后归属及解锁保留、多页面并发写入保护。
- `node tests/timers-browser.mjs`：通过自定义动作／明确重量口径、短时训练秒级计时、前台休息提醒，以及完成保存后不再被延迟自动保存恢复为草稿。
- 截图和虚构测试备份在忽略目录 `test-results/`；图片接触表可用 `node scripts/contact-sheet.mjs` 生成。
- 依据 [MDN IndexedDB 指南](https://developer.mozilla.org/en-US/docs/Web/API/IndexedDB_API/Using_IndexedDB) 与 [事务完成事件](https://developer.mozilla.org/en-US/docs/Web/API/IDBTransaction/complete_event)，保存成功仅在事务完成后报告。

- 最新动画专项与浅深主题验证通过，具体覆盖、22 种动画及 2 项素材阻塞见 `ANIMATED_COMPANIONS.md`。
