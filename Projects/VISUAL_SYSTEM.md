# 界面与模型精修：Atelier 版

> 最新界面：应用名为 AllenOne，用户要求 Google 系风格；以 `MATERIAL_UI.md` 为当前 UI 规范。本文 Atelier 配色与排版保留为历史，不再作为实现基线。

> 动画方向变更：用户否定本轮模型效果并已选择预渲染立体动画，见 `ANIMATED_COMPANIONS.md`。下文模型细化是历史记录；浅深主题仍为当前界面基线。

更新：2026-10-02。

## 用户要求

用户认为当前模型仍粗糙，要求精修模型、整个 UI 更高级，并提供浅色与深色主题。当时要求保留差异姿态、实时 3D、低成本和本机数据；实时模型路线现已被 D018 替代，见上方最新方向。

## 当前设计与实现

- 浅色：暖白石色背景、深灰绿正文、低饱和草木色舞台、少量黄铜色细节。
- 深色：深墨绿背景、分层深色面板、浅暖色正文、柔和绿灰控件。表单、弹窗、导航、提示与图鉴使用同一套语义色值。
- 重排字体与数字层级，细化边框、间距、按钮和导航；移动端使用浮动底部导航。
- 页面右上角可快捷切换浅／深；“我的 → 外观”支持浅色、深色、跟随系统。首次默认跟随系统，手动选择优先，跨刷新保留。
- 主题是此设备的显示偏好，存于 localStorage `wildfit-appearance`，不进入运动备份，不改变 IndexedDB 数据或计分规则。存储不可用时仍允许本次切换。
- 首屏样式加载前应用偏好，减少错误主题闪屏。运行中系统颜色变化可更新 UI 与 3D 灯光；切主题不重建模型或重置镜头。

具体颜色与材质是本轮代理设计选择；用户未逐项确认最终美术，不能把本轮通过技术检查记成用户审美验收。

## 模型精修

- 增加保留关节厚度的曲面管，替换四足腿部与马／羊／鹤颈部的尖锥连接；四足肩胯与躯干做平滑合并。
- 长曲线自适应细分，改善蛇身、龙身等可见多边形折痕；提高较低分辨率雕塑曲面的下限。
- 眼睛收窄外圈，增加与皮肤衔接的眼睑，降低突出的金属环感。
- 虎纹及身体渐变写入表面顶点颜色，不使用漂浮线条；加入细毛、羽纹和鳞片程序凹凸纹理。
- 鸟类补分层覆羽、猫头鹰面盘／眉羽、鹤顶冠、鹦鹉翼色与孔雀眼纹；羊毛采用贴合身体的实例化小绒团。
- 海龟壳片改为沿曲面绘制的蜂窝缝线；补鲸嘴线、水母伞缘和伞骨等细节。
- 改善灯光、地面接触与投影；角色自身不接收实时阴影以避免程序曲面上的自阴影伪影，展示台接收投影。两套主题分别设置环境亮度与舞台材质。
- 保留原有种类姿态、动画和成长预览，不更改分数；此版仍为程序模型，不声称替代专业雕刻／拓扑制作或已通过真机性能验收。

## 代码入口

- `app/theme.js`：首屏主题与本机偏好；`app/atelier.css`：语义色值和所有页面的视觉覆盖。
- `app/model-kit.js`：平滑曲面、连接、眼睛；`pet-models.js`：物种结构；`model-finishing.js`：材质与物种细节；`pet-view.js`：展示台、阴影、主题灯光。
- `tests/appearance-browser.mjs`：主题持久化、系统变化、业务数据不变、模型不重建、桌面／手机全页面与表单、24模型双主题、离线切换。
