# 动态 3D 精灵原型

本项目的视觉与交互探索，不是完整健身 PWA。包含兔、龙、海豚、鹰四种原创几何角色，支持待机动作、眨眼、摆耳／摆尾／扇翼、打招呼、旋转缩放、暂停以及五档成长预览。

五档为演示参数，不绑定真实分数，不确定最终成长门槛。没有生成或读写用户运动、饮食与分数数据。当前为第二版细化探索，最终美术效果待用户评审。

第二版在 `pets.js` 中生成连续身体曲面、弯曲耳角、翼膜、分层羽毛与物种动作，使用程序纹理区分材质；`main.js` 管理环境照明、展示台、镜头与交互。仍为程序几何模型，尚未产出 GLB 或骨骼动画资源包。

## 本机运行

在本目录执行：

```powershell
npm.cmd ci --ignore-scripts
npm.cmd start
```

打开 <http://127.0.0.1:4173>。服务仅监听本机；手机不能通过这个地址访问。若端口已被本原型占用，直接打开即可。

依赖安装完后，页面资源都从本地加载，不依赖运行时 CDN、图片 API 或付费模型服务。当前未配置 PWA 安装与离线缓存。

## 技术与验证

- Three.js 0.180.0，遵循其 MIT 许可证；原型使用原生 JavaScript 与 WebGL 2。参考 [Three.js 文档](https://threejs.org/docs/)。
- 启动服务后执行 `npm.cmd run check`，使用已安装的 Microsoft Edge 完成浏览器检查；需要开发依赖 Playwright。
- 已验证四角色第 1／3／5 档形态、实际渲染、暂停／恢复、打招呼、自动环绕、键盘操作、390px 布局及减少动态效果偏好；重复切换后几何体／纹理计数稳定，无 JS、着色器或请求错误。
- 本版截图保存在 `Projects/assets/pet3d-v2-*.png`，旧版截图保留。已作桌面与手机宽度目视检查；尚未进行真实 iPhone Safari 或帧率／耗电测试。
- 支持触摸拖动与双指缩放；页面隐藏时停止角色时间推进与渲染。具体最终手机性能预算待确定。
